# MiniFader

Simple addon to show frames on mouse hover, otherwise hide them. Shows a nicer fade in/out animation when the mouse enters/leaves the frame.

This helps to declutter and simplify your UI for a minimalistic approach.

Currently supported frames include:

- Bags bar
- Micro menu
- Objective/quests tracker
- Raid manager flyout
- XP and reputation bars
- Collapse/expand buffs arrow.
- Chat tabs and icons.
- Blizzard's damage meters.
- More to come!

Configure which frames to fade with /minifader or /mf.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
